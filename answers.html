Git Assignment Answers

Restoring Version 1

Checking out Version 1 of index.html replaced the file in the working tree and staging area with its older contents. The Version 2 and Version 3 commits were not deleted; they remained safely stored in Git history and could be restored again from the current main commit.

Detached HEAD

Checking out an old commit directly moved HEAD to that commit instead of to a branch. Returning to main attached HEAD to the main branch again.

Branch Recovery

The feature/contact branch was deleted after its commit. The commit was found in git reflog, and the branch name was recreated at that commit.

Tags

The annotated v1.0 tag identifies the first website version, while v2.0 identifies the completed main-branch assignment version.
